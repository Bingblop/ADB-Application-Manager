Handy to know
  • Back closes the open sheet, steps up a folder or out of an archive, then returns to the tab you came from. Leaving takes a second, deliberate press.
  • Press and hold an app or a file to select several, then act on them all at once.
  • File Manager → View opens an APK or ZIP without extracting it. Edit it, tap Sign, then install it.
  • Installs started from File Manager always go through ADB, Wireless Debugging, Shizuku or Root, never the system installer.
  • ADB Console → Rish is a persistent Shizuku shell: cd and variables stay put between commands.
  • Logcat can show one app only. Tap Logs in an app's ⋯ menu.
Privacy
No account, no ads, no analytics and no server of ours. Everything runs on your phone. The app only goes online for something you open or ask for: update checks, App Stores, the debloat list, and a VirusTotal lookup if you add your own key.
