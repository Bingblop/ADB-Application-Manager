Patch apps with Morphe on this phone: pick the patches, let the app build and sign the APK, and install it. The patcher is the Morphe project's own engine, built into this app, and everything works the way Morphe Manager works: patch sources, a community finder, Simple and Advanced patching, a live log, and a list of patched APKs.

Where to find it: the tab bar, after Connected Devices and before About. If it is not there, it has been switched off in the Feature List.

Careful. A patched app is not the app from the store. It is signed with a key made on this phone, so Android will not install it over the original unless the original is removed first (the app asks, and says that its data goes with it). Patches belong to their authors: only add sources you trust.

Under the card there are two pages: Apps lists the apps your sources have patches for, Community is the finder for more sources. The credit line on the card names the people whose work this is; the same names are in Credits and licences.

The first time

  1. Open the tab. The Apps page offers Download Morphe Patches, the official source (about 11 MB). Tap it.
  2. The app reads the patches (a few seconds, in a process of its own). The apps they fit appear, the ones installed on this phone marked Installed.
  3. Tap an app, choose the patches, tap Patch.
Tip. If a card at the top says this build of the app does not contain the Morphe engine, patching is switched off in that build. Sources, the finder and downloads still work. A release build has the engine.

A patch source is a bundle of patches, a .mpp file. Morphe Patches, the official one, is there from the start; you can add as many more as you like.

Open Sources. Each card shows the name, the repository, the version, the number of patches, when it was updated and its size, with badges: Pre-installed, Local file, Off, Not downloaded, Needs a newer Morphe (the bundle was made for a newer patcher than this app carries), Metadata not available (the address could not be read, the bundle you have still works) and Update followed by a version.

Adding a source

Tap + Add a source. On Remote paste the address of a GitHub or GitLab repository, or of a .json metadata file: github.com/owner/repo, gitlab.com/owner/repo, example.com/patches-bundle.json. The box tells you at once whether the address is usable. A link from the finder, morphe.software/add-source?github=owner/repo, works too. Tick Pre-release patches to follow the early releases. On Local file pick a .mpp from storage; a local source never updates on its own.

Only add sources you trust. A patch source decides what ends up inside your patched apps. The app downloads the bundle over https only and refuses a file that is not a patch bundle, but it cannot tell you what a patch does.

Check for updates asks every remote source whether a newer version exists and marks the ones that have one.

The Community page lists the patch bundles other people publish for Morphe. It shows what morphe-patches.software, the finder of the Morphe project, publishes, loaded when you open the page and kept for six hours (offline, the last copy is shown and says so).

  • By app lists apps that have community patches, with their category and how many bundles patch them. Tap one for its description, the versions the patches name and the bundles that patch it. The featured apps are along the top.
  • Bundles lists the bundles: name, repository, author, stars, number of patches, the apps they patch.
  • Search, the category drop-down and the sort (Popular, Most stars, Recently updated, Name A-Z) narrow the list.
  • Only patches for apps installed on this phone keeps what fits the apps you have.
  • A bundle you have already added shows Installed in green with a glow. An app on this phone shows On this phone.

Tap Add on a bundle (or Add this source in its sheet). The app asks first, downloads it and lists it under Sources. The finder is community-maintained: its bundles are not checked by the Morphe project or by this app.

Tap an app on the Apps page (or Patch a file to patch an APK, APKS, APKM or XAPK you have) to open its patch page.

The APK

The top card shows the app, whether it is Installed on this phone or From a file, its version, and whether the version is one the patches were made for (Supported version in green, or Other version). Most patches work with only the versions they list. If yours is not one, use Get the APK with Morphe Helper (see Morphe Helper) or Choose an APK file.

Simple and Advanced

  • Simple chooses for you: the patches of the first source that has some for this app which are on by default and fit the version. You see the list and the Patch button.
  • Advanced lists every patch with a tick box: App-specific patches for this app and Universal patches that fit any app, with a search box and All, None and Defaults. A patch with options has a gear: text, numbers, switches, choices, sliders, colors and files. With more than one source, each has its own tab.

Patch

The Patch button has two boxes next to it. Install when finished (on) installs the patched app through the working mode, silently over ADB, Shizuku or Root; with none, the system installer asks you. Delete the APK after installing (off) removes the patched APK once the install worked.

While it runs you see the steps (Preparing, Loading, Unpacking, Patching, Rebuilding, Signing, Saving, Installing), a progress bar and a log in the style of logcat, with a level filter, Follow, Copy and Share. A notification keeps it going if you leave the app and has Cancel. When it is done you get the file name and size and Install, Share, Save to Downloads.

When it fails

When one patch fails, the patches that need it fail too ("depends on ..., which raised an exception"). The card leads with the first error, whose details are open, and folds the others into one line, N more failed only because a patch they need failed, with Show to name them. Fix the first one and the rest go away.

The result card names the step and the patch that failed, shows its full details (the error and stack trace), says in plain words what usually causes it, and offers Back to the patches, Copy the log, Share the log and Retry, skipping failed patches. The usual causes: the version is not supported, the phone ran out of memory (try Strip unused native libraries), or the bundle needs a newer Morphe.

Most patches need one exact version of the original app. Morphe Helper finds that APK on the sources you choose, downloads it, checks it, and lets you install it or patch it. It follows the open-source app Helper for Morphe by rushiranpise, built into this app.

Download

Enter the package and the version (empty: the newest), choose the CPU and the source, then:

  • Fast mode walks every source that is on until one delivers.
  • This version looks for exactly that version; Newest for the newest.
  • All versions lists what a source has, with format and size, and a Download button for each. For APKMirror, whose app page shows only the latest releases, Helper also reads the pages of its See more uploads list (up to eight) to reach older versions; This version does that too when the version is not on the app page. If APKMirror blocks those pages, you get the newest ones only: use Open the site.
  • Open the site opens the source in the browser, for the ones that cannot be downloaded from here (they say why). Save the file there; when you come back, Helper looks in Downloads by itself.
  • Find in Downloads lists the APK, APKM, APKS and XAPK files in your Downloads folder (and the folders directly inside it) that hold the package you typed, newest first, each with its version, format and number of parts. Helper opens every file to read the package, so the name does not matter (method.latin_18.0.3..._apkmirror.com.apkm is found for com.google.android.inputmethod.latin). Use takes a file. This needs All files access; without it the list says so and offers to grant it.
  • Pick a file opens Android's file picker, for a file anywhere else.

Bundles. Many sources hand out an app as a bundle: APKM (APKMirror), APKS and XAPK, a zip of the base APK and its split APKs. Helper downloads them like an APK (a source's list says which format each version has), reads the package and version from inside, and shows APKM, 5 parts. The patcher merges the parts itself, so Patch this file works on a bundle as it is. Install all parts puts every part on the phone in one session: through the working mode silently, or, without one, through Android's installer, which asks you once.

A downloaded file is checked: its hash against the one the source published, and its real manifest (package, version, build) against the request. A file that does not match is refused. You then get Install this APK (Install all parts for a bundle; through the working mode), Patch this file, Share, and, when VirusTotal is on, Scan with VirusTotal.

Settings

  • Sources: switch each of the ten (APKMirror, Uptodown, APKPure, APKCombo, Aptoide, Evozi, Mi9, APK Downloader, Aurora, Play) on or off, and pick the default. Some can be downloaded directly; the others open in the browser.
  • Connection: Wi-Fi and mobile data, Wi-Fi only, or mobile data only. Save downloads: the app's cache or Download/Helper for Morphe. Clear after use. Fast mode: version.
  • VirusTotal: optional. Paste your API key (a free one allows 4 lookups a minute and 500 a day), press Test, and choose Never, Ask or Always. A file VirusTotal already knows is looked up by its SHA-256 and not uploaded again (a cached report). Bundles are opened and each APK inside is checked. The quota bars show what is used. The key is kept on this phone and is sent only to VirusTotal.
Good to know. Helper is independent of the sites it uses. Their pages, versions and formats can change at any time, and a source that changed says so and sends you to the browser.

The Patched APKs button lists every APK you have patched, newest first, with the app, the version, the date, the size, the patches that were applied, and Installed once it was installed.

  • Install installs it again. If Android refuses because the installed app has another signature, the app offers to uninstall the installed copy first and says that its data goes with it.
  • Share sends the APK to another app. Save to Downloads copies it to Download/Morphe Patcher.
  • Log shows the log of that run. Delete removes the APK and its log; the app on the phone is not touched.
