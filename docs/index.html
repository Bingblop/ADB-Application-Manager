What it does

Debloat in minutes

The 5,000-package UAD-NG list, a review step before anything runs, and one-tap Undo for every change. Freeze, uninstall or suspend system apps.

Install and update

.apk, .apks, .apkm and .xapk with every pm install flag. Updates from GitHub, F-Droid, IzzyOnDroid, APKMirror, Galaxy Store and your own stores.

Extra Settings

Private DNS with fifteen services and a built-in speed test, animation speed, brightness bias, device telemetry, power and reboot, Doze, zram. Every change reads the phone back.

Hidden settings and overlays

Android's Global, Secure and System tables with plain-English descriptions, read-back proof and Undo. Material You colours and system overlays.

Console and Terminal

ADB Shell with a history of cards and Live Logcat. A real pty terminal with vim and htop, your own Termux, and optional AI coding agents that run commands only with your OK.

Inspector, files, cleaner, patcher

Ten tabs per app (permissions, components, manifest, signatures). A privileged file manager. SD Maid's four cleaning tools. Morphe patching on the phone.

Screens

Screenshots come from the app's UI test harness (mock data, dark theme). More, including the light theme, in the full guide.

Install in 30 seconds

  1. Download the APK above and open it; allow installs from your browser or file manager.
  2. Pick a working mode: ADB over TCP (run adb tcpip 5555 once from a computer), Wireless Debugging on Android 11+ (pairing from inside the app, no computer), Shizuku, or root. Without one, the app opens read-only and still shows everything.
  3. Updating later: install the new APK over the old one, let the app tell you, or use Obtainium.

Honest notes

Testing

Every change runs a UI suite and Java suites on a computer. Testing on phones is thin and community-driven; the device checklist lists the steps, and a bug report that names a step is the most useful thing you can send.

Not on Play, F-Droid or IzzyOnDroid

The working modes are outside Google Play's rules. F-Droid and IzzyOnDroid exclude apps that integrate with AI services, which the optional coding agents do. GitHub Releases and Obtainium are the channels.

Privacy

No ads, no account, no analytics, no server of ours. Your ADB key is generated on the phone. The only network calls are the ones you start: update checks, downloads, and the agents you configure with your own keys.
